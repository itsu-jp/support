A small memory tool

忘れたことを、
責めないために。

Itsuは、予定を詰め込むアプリではありません。最後にした日を静かに残して、次に思い出すきっかけをつくります。

A / 記録

「今日やった」で終わる

入力を短く、表示をわかりやすく。ホームを開けば、前回から何日経ったかが見えます。

↗
B / あいまいさ

正確じゃなくても、残せる

「先週ごろ」「月の上旬」も、無理に1日に決めず日付の範囲として保存します。

〜
C / ふり返り

いつもの幅を知る

過去の間隔から、そろそろかもしれない時期を表示。期限や診断ではない、あなたの目安です。

◌

Itsu Plus

自分らしいアイコンと、
いつでも見えるウィジェット。

好きな絵文字を項目アイコンに。ホーム画面には、よく使う項目と経過日数を置いておけます。

Quiet by design

記録は、あなたのiPhoneに。

Itsu独自のアカウントやサーバーは使いません。項目、履歴、写真は端末内に保存します。
